# Kozmo

Kişisel gökyüzü rehberi — doğum anındaki gökyüzünü gerçek astronomik
hesapla (astronomy-engine) okur, günlük skorlar, Aura kartı ve kozmik
takvim sunar. Eğlence ve ilham amaçlıdır.

Stack: Vite + React + Tailwind CSS v4 + lucide-react + astronomy-engine.
Yapı: src/lib (hesap ve motor) · src/content (metin havuzu) ·
src/i18n (dil dosyaları, EN'e hazır) · src/components (arayüz).

Çalıştırma: `npm install && npm run dev` — ayrıntı için DEPLOY.md.
